# Suganesh V S — Personal Portfolio

A fast, responsive, dark-themed personal portfolio built with HTML5, CSS3, and Vanilla JavaScript. Designed to highlight projects in AI engineering, RAG pipelines, MongoDB architecture, and modern front-end web development.

## Features

- **Dark Visual Design:** Custom ambient glow backgrounds, CSS grid overlays, and neon accent design system.
- **Draggable Project Showcase:** Interactive drag-to-scroll horizontal project gallery with smooth touch/drag controls.
- **Dynamic Filtering:** Filter projects by category (AI/ML Architecture, Front-End, Database Systems) with client-side rendering.
- **Credential Modals:** Interactive popups showcasing 4x MongoDB Certifications and TCS iON NQT credentials with verification links.
- **Service Stack & Technical Skills:** Clear breakdown of development capabilities, tech stack tags, and proficiency areas.
- **Responsive Layout:** Optimized across mobile, tablet, and desktop screens without reliance on heavy CSS frameworks.

---

## Built With

- **HTML5 & CSS3:** Semantic markup, CSS Custom Properties (Variables), Flexbox, and CSS Grid.
- **JavaScript (ES6+):** DOM manipulation, modal handling, copy-to-clipboard, and local storage management.
- **FontAwesome 6 & Google Fonts:** Inter & Fira Code fonts paired with developer iconography.
